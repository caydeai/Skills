## Available skills

### [`niche-scout`](./niche-scout)
Research a niche before committing to a business build. Outputs a full opportunity pack: competitive landscape, design patterns, market gaps, pricing analysis, and a go/no-go scorecard.

Works on identity-based niches (e.g. "dog mom"), product-type niches (e.g. "minimalist wall art"), or service niches (e.g. "freelance pixel art commissions").

[Install instructions →](./niche-scout/README.md)

## What is a Claude Skill?

A Claude Skill is a structured prompt + workflow that Claude auto-loads when relevant. Skills work in [Claude.ai](https://claude.ai) (web/desktop) and [Claude Code](https://claude.ai/code) (CLI for developers).

To install a skill, follow its individual README. Each skill includes setup instructions for both Claude paths.
